# Theme Preference & Personalization (Roadmap Item 4)

## Overview
`ThemePreferenceToggle` is a compact UI component that lets users explicitly override the system's color scheme. It persists the preference in `localStorage` and feeds the `ThemeAgent` for personalized recommendations.

## Toggle Cycle
The cycle mode cycles through four states on each click:

```
system -> light -> dark -> (null) -> system
```

| State | Meaning | Storage |
|-------|---------|---------|
| `null` | Auto / follow system | key removed |
| `'system'` | Always respect OS preference | `system` |
| `'light'` | Force light theme | `light` |
| `'dark'` | Force dark theme | `dark` |

Auto-clear (removing the key) only happens on explicit user interaction, not automatically.

## Popover Mode
When `popoverMode={true}`, three inline buttons replace the cycle:

```tsx
<ThemePreferenceToggle popoverMode={true} />
```

Users click an explicit option instead of cycling. `aria-pressed` highlights the active choice.

## Persistence
- **Storage key**: `oryx-theme-pref`
- **SSR fallback**: in-memory store when `localStorage` is unavailable
- **Multi-tab sync**: `storage` event listener updates all open tabs
- **No auto-clear**: the override persists across page reloads and sessions

## ThemeProfile
Generated by the AI in Sprint 3. A `ThemeProfile` contains:

```ts
type ThemeProfile = {
  id: string
  name: string
  light: { primary: string; bg: string; text: string }
  dark: { primary: string; bg: string; text: string }
  acceptedAt: Date | null
}
```

Accepted profiles are stored in the agent and available via `useThemeAgent().aiProfile`.

## Accessibility
- `aria-label` on the toggle button
- `aria-pressed` on popover option buttons
- Full keyboard navigation (Tab / Space / Enter)
- Visible focus ring via `focus-visible:ring-2`
